# 03 – S&P 500 Simulation

**File:** `sp500_simulation.cpp`

- Shows a **risk warning** first. The user must type `Y` to continue.
- Grows the money at a **fixed 7% per year** (a guess, not a promise).
- Prints a year-by-year table: gain and balance.
- Uses a `for` loop instead of `pow()` (Gaddis Ch. 5).

**Compile and run:**
```
g++ sp500_simulation.cpp -o sp500
./sp500
```
