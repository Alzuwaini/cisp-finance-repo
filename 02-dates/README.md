# 02 – Dates

**File:** `dates.cpp`

- A `Date` struct holds month, day, year (Gaddis Ch. 11).
- Checks real calendar dates: Feb 29 only in leap years, 30/31-day months.
- Shows time passed as years, months, days, plus total days.
- No date libraries: day counts are added up with loops (Gaddis Ch. 5).
- Will move into `07-input-date-utils` later.

**Compile and run:**
```
g++ dates.cpp -o dates
./dates
```
